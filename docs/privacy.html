Privacy

Last updated: October 13, 2026

Short version: your files stay on your computer. To answer you, the messages you type and the code the agent works on are sent to the AI providers that power Gardely AI. The app sends a tiny anonymous “I was opened” signal so we can count users — you can turn it off.

1. AI requests

When you ask Gardely to do something, your message, the project context the agent reads (for example the content of files it opens) and its tool results are sent to third-party AI inference providers to generate the answer. Don't paste passwords, API keys or other secrets into the chat. Providers may keep request logs according to their own policies; free tiers may use prompts to improve their models.

2. Anonymous usage stats (optional)

If “Share anonymous usage stats” is on (Settings → General → Privacy), the app sends:

  • a random install ID created on your computer (not linked to your name, email or account);
  • the app version and operating system name;
  • event names such as “app opened”, “shared”, “task finished”.

We never send file names, file contents, prompts, code, paths or anything you type. Turn it off any time in Settings — nothing is sent after that.

3. Website and downloads

When you download GardelyCode from gardelycode.com we count the download and where it came from (for example “YouTube”). To count unique downloads per day we use a one-way hash of your IP address and browser with a salt that changes every day and is never stored — we cannot recover your IP address from it. We do not use cookies or third-party trackers.

4. Updates

The app checks gardelycode.com (and GitHub as a fallback) for new versions. Updates are cryptographically signed; the app refuses anything without our signature.

5. Your choices

  • Turn off stats in Settings → General → Privacy.
  • Delete the app's data folder (Settings → About → Open data folder) to remove your chat history and install ID.

6. Contact

Questions? Open an issue at github.com/null-byte00/gardelycode-community.
