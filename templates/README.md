# Templates — ideas you can grow in one message

Open an empty folder in GardelyCode, keep the default model (**Claude Opus**), paste a prompt, press Enter.

| # | Build | Prompt |
|---|---|---|
| 1 | ☕ Café landing | `Make a one-page site for a coffee shop called "Bean & Bloom": menu with prices, opening hours and a table booking form. Warm colors, works on phones.` |
| 2 | 🐍 Snake game | `Make a snake game in the browser with a start screen, score, best score and touch controls for phones. Make it feel juicy.` |
| 3 | ✅ To-do app | `Build a to-do list app with categories, due dates, drag-and-drop reordering and dark mode. Save everything in the browser.` |
| 4 | 💼 Portfolio | `Create a personal portfolio for a designer named Alex: hero, project gallery with filters, about section and a contact form.` |
| 5 | ⏱️ Pomodoro | `Make a pomodoro timer with a circular progress ring, custom durations, sounds and a stats chart for the week.` |
| 6 | 🧮 Calculator | `Build a beautiful calculator with history and keyboard support. Make it look like a premium app.` |
| 7 | 🎨 Color palettes | `Make a color palette generator: press space for new palettes, lock colors, copy hex codes, export as PNG.` |
| 8 | 🌦️ Weather card | `Create an animated weather card for 5 cities with day/night themes and smooth transitions (use sample data).` |
| 9 | 🃏 Memory game | `Make a memory card game with 3 difficulty levels, a timer, flip animations and a win screen with confetti.` |
| 10 | 📝 Markdown notes | `Build a notes app with a markdown editor, live preview, search and tags. Save notes in the browser.` |

Then keep growing it: *"add a dark mode"*, *"make the buttons bigger"*, *"translate to Russian"*, *"add a leaderboard"*.
